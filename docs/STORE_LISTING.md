# Chrome Web Store 文案

## 名称

渐读｜网页英语学习助手

## 简短说明

把中文网页逐步变成中英混合阅读环境，用可控难度和密度自然积累英语词汇。

## 详细说明

渐读帮助中文用户在日常网页阅读中获得低压力的英语输入。它会根据你选择的 CEFR 参考难度和替换密度，将部分中文词汇或短语替换为自然英文；悬停可看中文释义，点击可标记“认识”或“太难”。

主要能力：

- 本地优先，无账号也能使用
- 3,189 条内置词汇与自定义词表
- A1–C2 参考难度与三档替换密度
- 生词本、学习统计和简易间隔复习
- 可选 DeepSeek、Ollama 或 OpenAI-compatible AI 语境增强
- 按网站单独授权自动运行
- 一键恢复原文

隐私说明：本地模式不会发送网页文字。AI 模式只会把待处理的短文本发送到用户自行配置的接口。扩展不包含广告、分析 SDK 或账号追踪。

## 类别

Education

## 单一用途说明

在用户阅读中文网页时，根据可配置难度将少量中文词汇替换为英文，并提供释义与学习记录，帮助用户进行渐进式英语学习。
